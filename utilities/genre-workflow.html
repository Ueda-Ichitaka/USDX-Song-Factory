Genre utilities workflow

Four host tools. The first two fill in genres that are missing; the other two break every genre down into its bases, so Symphonic Black Metal becomes Symphonic, Black, Metal. Each pair writes a tab-separated file for you to check, and the library only changes when you run the second script with --apply.

The four tools

genre_lookup.py

reads library

Finds songs without a genre and asks online sources which genres they belong to.

Reads
  • every song file under --library
  • MusicBrainz for each song: the recording, else its album, else the artist
  • Wikidata and Last.fm, once per artist
  • LASTFM_API_KEY from the environment or stack/.env
Writes
  • library-genres.tsv: every song
  • genre-predictions.tsv: songs without a genre, with the predicted bases (all of them) and each source's raw answer
  • genre-cache.json
Missing
no #GENRE, an empty one, or Unknown, No idea, Other, None, Misc (--keep-placeholders keeps those)
Time
about an hour for 823 songs; MusicBrainz allows about one request a second

apply_genres.sh

writes library

Writes the predicted genres you kept into the song files.

Reads
genre-predictions.tsv; an empty predicted genre cell skips that song
Writes
#GENRE into songs that still have no genre or a placeholder; a song that got a genre since the lookup is left alone
Backup
library analysis/genre-backup-<time>/, or --backup DIR
Keeps
byte order mark, line endings, cp1252 encoding

genre_clusters.py

reads library

Breaks every genre spelling down into its bases. The same rules (genre_bases.py) turn looked-up genres into bases.

Reads
  • every #GENRE under --library, split at commas
  • the MusicBrainz genre list, downloaded once
Splits
  • at spaces, hyphens, slashes: Mittelalter-Rock → Mittelalter, Rock
  • one-word genres whose halves are genres: Synthpop → Synth, Pop
Keeps
names that mean one thing: Hip-Hop, R&B, K-Pop, Rock and Roll, A cappella, ...; Metalcore, Tanzmetal
Fixes
  • translations, short forms: Alternativo, Alt., BSO; Mittelalter stays
  • filler words: Electronic Music → Electronic
  • dropped: Easy Listening, Singer-Songwriter; Video Game Music → Soundtrack
  • typos: Ghotic, Trash
Writes
genre-clusters.tsv, genre-overview.tsv, library-genres.tsv

normalize_genres.sh

writes library

Rewrites the existing genre tags with the bases you settled on.

Reads
genre-clusters.tsv (spelling → bases) and library-genres.tsv (--songs, the paths)
Writes
each part replaced by its bases, in order, duplicates dropped, joined with ", "; parts the file doesn't list stay as they are
Skips
songs without a genre or with a placeholder; an empty genre cell leaves that spelling as it is
Backup
library analysis/genre-normalize-backup-<time>/

Run order

  1. Look up 
    python3 utilities/genre_lookup.py --library /dhuaddan/media/ultrastar/songs
  2. You check

    Open library analysis/genre-predictions.tsv in LibreOffice as tab-separated text. Correct the predicted genre column, empty a cell to skip that song, and save in the same format.

  3. Write genres 
    utilities/apply_genres.sh            # dry run: lists what it would set
utilities/apply_genres.sh --apply
  4. Propose bases 
    python3 utilities/genre_clusters.py --library /dhuaddan/media/ultrastar/songs

    Run it after step 3, so the genres you just added are checked too.

  5. You check

    In genre-clusters.tsv, change a genre cell to the bases you want (comma-separated), - to drop that spelling, or empty it to keep that spelling. Worth a look: Grog’n Roll, Electro Hop (gives a base "Hop"), Neo-Classical.

  6. Write bases 
    utilities/normalize_genres.sh        # dry run: old -> new per song
utilities/normalize_genres.sh --apply
